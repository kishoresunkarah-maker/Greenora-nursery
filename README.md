# GREENORA Nursery Website

Responsive custom-coded static website for GREENORA Nursery.

## Files
- `index.html` — page structure and brand content
- `styles.css` — responsive luxury forest-green, gold and cream styling
- `script.js` — category filters, catalogue search, mobile navigation and WhatsApp enquiries

## Preview
Extract the ZIP and open `index.html` in a modern browser. Internet access is needed for sample plant photos and Google Fonts.

## Free publishing options
This is a static website with no paid server or database required. It can be hosted on free static hosting such as GitHub Pages (https://pages.github.com/) or Netlify (https://www.netlify.com/). A custom domain is optional and usually costs extra.

## Before launch
- Replace sample Unsplash images with your own nursery photos when available.
- The catalogue currently lists categories, not confirmed live stock or prices.
- The form does not store enquiries; it opens WhatsApp with a pre-filled message and the visitor must press Send.
- Verify the contact number and address before publishing.
